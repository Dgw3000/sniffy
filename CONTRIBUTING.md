# Mitwirken

Fehlerberichte und Verbesserungsvorschläge sind über GitHub Issues willkommen.

Bitte beachte:

- Keine realen Dosierungs-, Mengen- oder Verträglichkeitsfunktionen hinzufügen.
- Keine Werbung, Tracker oder proprietären SDKs einbauen.
- Die App muss offline nutzbar bleiben.
- Neue Abhängigkeiten müssen freie Software sein und dokumentiert werden.
- Eigene Änderungen unter GPL-3.0-only veröffentlichen.
