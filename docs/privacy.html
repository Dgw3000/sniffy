DATENSCHUTZ

Keine Cloud. Keine Tracker.

Stand: 22. Juli 2026

Lokale Verarbeitung

Sniffy funktioniert vollständig offline. Die App übermittelt keine Daten an den Betreiber oder an Dritte.

Freiwillig eingegebene Namen beziehungsweise Aliase, erzeugte Spaßnamen, Zentimeterwerte und lokale Ranglisten werden ausschließlich im lokalen App-Speicher beziehungsweise Browser-Speicher des verwendeten Geräts abgelegt.

Keine externen Dienste

Sniffy verwendet keine Werbung, keine Analyse- oder Trackingdienste, keine Cloud-Synchronisierung, keine externen Schriftarten und keine proprietären SDKs.

Daten löschen

Die Rangliste kann innerhalb der App über „Lokale Rangliste löschen“ entfernt werden. Alternativ können sämtliche App-Daten über die Android-Systemeinstellungen oder die Browser-Einstellungen gelöscht werden.

Berechtigungen

Die Android-App fordert keine Netzwerkberechtigung und keine sonstigen sensiblen Android-Berechtigungen an.

Kontakt

Fragen und Hinweise können über die GitHub Issues des Projekts eingereicht werden.
