Datenschutz

Grundsatz

Diese Website verwendet keine Werbenetzwerke, keine Analyse-SDKs, keine Tracking-Cookies und keine Benutzerkonten.

Hosting über GitHub Pages

Die Website wird über GitHub Pages bereitgestellt. Beim Abruf können technisch notwendige Serverprotokolle durch GitHub verarbeitet werden, beispielsweise IP-Adresse, Zeitpunkt, aufgerufene Datei, Browsertyp und Referrer. Es gelten ergänzend die Datenschutzinformationen von GitHub.

Downloadzähler

Der auf der Startseite angezeigte Downloadzähler liest ausschließlich die öffentliche Anzahl der Downloads aus der GitHub-Releases-API aus. Dabei wird kein eigenes Nutzerprofil angelegt und keine personenbezogene Downloadstatistik durch diese Website geführt.

Sniffy

Die Android-App Sniffy funktioniert vollständig offline. Freiwillig eingegebene Namen, Aliase und Ranglistenwerte werden ausschließlich lokal auf dem jeweiligen Gerät gespeichert.
