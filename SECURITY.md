# Security Policy

Sniffy verarbeitet keine Serverdaten und besitzt keine Netzwerkberechtigung. Sicherheitsprobleme sollten dennoch nicht öffentlich mit sensiblen Details gemeldet werden.

Bitte eröffne zunächst ein knappes GitHub-Issue ohne vertrauliche Daten und bitte dort um einen privaten Kontaktkanal.

Unterstützt wird jeweils die aktuelle veröffentlichte Version.
